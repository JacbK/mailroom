Switchboard by Jacob Kieser

I wanted one agent for all my Gmail accounts.

So I made this. It is a small local plugin for Codex and Claude. Add as many accounts as you want, search all of them, or pick one.

That is pretty much it.

What it actually does

Search and read email, make drafts, send or forward stuff, change labels, archive, and move messages to Trash. It only writes when you ask.

Where your email goes

Mostly nowhere. The plugin runs on your Mac. OAuth tokens live in Keychain. There is no hosted backend, database, analytics, or telemetry. When you ask Codex or Claude to work with an email, that email goes to whichever client you picked.

How it avoids the wrong inbox

Every message, draft, label, and thread ID includes its account. The agent never has to guess. Also, trash means Gmail Trash. It cannot permanently delete email.
