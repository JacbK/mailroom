Mailroom setup

Connect your personal Google app

Keep the setup command running. It will find the OAuth file when Google downloads it.

1. Create a project

Create a Google Cloud project named Mailroom Personal.

2. Enable Gmail

Select the new project, then enable the Gmail API.

3. Configure access

Open Google Auth Platform. Use Mailroom Personal for the app name and choose External unless this is for one Workspace organization.

Under Data Access, add https://www.googleapis.com/auth/gmail.modify.

4. Keep sign-in working

Under Audience, click Publish app. Leave it unverified and do not submit a verification request. Testing mode expires Gmail access after seven days.

5. Download the client

Under Clients, create a Desktop app named Mailroom on my Mac, then download its JSON. Mailroom will import it from Downloads, delete the file, and start Google sign-in.

Expected warning

Google may say it has not verified your personal app. Choose Advanced, continue to Mailroom Personal, review the Gmail permission, and allow it.

Stuck? Use the full setup guide. Google documents the personal-use exception and seven-day Testing limit.
