# Product

## Register

brand

## Users

People on macOS who use Codex or Claude Code and want one agent to work across several Gmail accounts without switching connectors or guessing which inbox an ID belongs to.

## Product Purpose

Mailroom is a small local plugin that brings normal Gmail actions to any number of accounts. Setup should start from one prompt, credentials should stay in Keychain, and account routing should remain obvious to both the user and the agent.

## Brand Personality

Casual, direct, and useful. It should feel like a good side project shared by the person who made it, not a startup landing page or a compliance document.

## Anti-references

Avoid polished SaaS language, long explanations, repeated conclusions, fake urgency, decorative feature claims, and copy that sounds generated. Do not make a simple tool feel bigger than it is.

## Design Principles

- Let someone understand the tool in one screen.
- Show the real install prompt instead of explaining the setup twice.
- Keep the visual language close to Persona: warm, sparse, and developer-made.
- Make local storage and account safety clear without turning the page into security marketing.
- Cut every word and element that does not help someone install or trust the tool.

## Accessibility & Inclusion

Keep the site responsive, keyboard accessible, readable at browser zoom, compatible with reduced motion, and at WCAG 2.2 AA contrast where practical.
